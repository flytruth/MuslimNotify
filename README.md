How to Use Muslimtify for Sarajevo

Compile it (requires a C compiler like gcc)
cd ~/MuslimNotify
git clone https://github.com/<your-repo>/Muslimtify.git
cd Muslimtify
make

Set location to Sarajevo
./muslimtify location set --city=Sarajevo --country=BA


Enable notifications

./muslimtify notification enable all


Set adhan audio (download Moayyad Hakeem’s adhan and set path)

./muslimtify notification --adhan set /path/to/adhan.mp3





Install as a daemon (Linux)
./muslimtify daemon install


Use the bash script for testing.
